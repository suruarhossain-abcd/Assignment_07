# 🛒 বাজার দর (Bazar Dor)

বাংলাদেশের প্রতিদিনের নিত্যপ্রয়োজনীয় পণ্যের বাজার দর জানার জন্য একটি আধুনিক ওয়েব অ্যাপ্লিকেশন। এর মাধ্যমে ইউজাররা সহজেই বিভিন্ন পণ্যের আজকের দাম, গতকালের তুলনায় দাম বাড়া-কমা ইত্যাদি দেখতে পারবেন।

## 🚀 Technologies Used
- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS & DaisyUI
- **Authentication:** Better Auth (Email/Password)
- **Database:** MongoDB
- **Notifications:** React Hot Toast
- **Icons:** React Icons

## ✨ Key Features
1. **সিকিউর অথেনটিকেশন:** ইউজাররা ইমেইল ও পাসওয়ার্ড দিয়ে সাইন-আপ এবং লগইন করতে পারবেন।
2. **রিয়েল-টাইম প্রোডাক্ট লিস্ট:** সব পণ্যের তালিকা, দাম এবং দামের ট্রেন্ড (▲/▼) দেখা যাবে।
3. **রাউট প্রোটেকশন:** লগইন ছাড়া ইউজার প্রোফাইল পেজে ঢোকা যাবে না (Protected Route)।
4. **রেসপনসিভ ডিজাইন:** মোবাইল এবং ডেস্কটপ সব ডিভাইসে সুন্দরভাবে কাজ করে।
